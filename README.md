# 🚗 Carlug

Plataforma web de **aluguel de carros**, onde clientes podem consultar veículos disponíveis e solicitar aluguéis de forma simples e rápida.

> 🚧 Projeto em desenvolvimento.

## 📌 Sobre o projeto

O Carlug é um sistema de aluguel de automóveis composto por um front-end em React e uma API própria em Express, que se comunica com um banco de dados. O objetivo é oferecer uma experiência moderna para quem quer alugar um carro e uma forma organizada de gerenciar os veículos e os aluguéis.

## ✨ Funcionalidades

- [x] Barra de navegação
- [ ] Carrossel de destaques
- [ ] Listagem de carros disponíveis
- [ ] Página de detalhes do veículo
- [ ] Cadastro e login de usuários
- [ ] Solicitação de aluguel
- [ ] Acompanhamento e cancelamento de aluguéis
- [ ] Integração com API externa

## 🛠️ Tecnologias

| Parte | Tecnologia |
|---|---|

| Back-end | Node.js, Express |
| Banco de dados | MySQL |
| Ícones | Font Awesome |

```
carlug-react/

```

## ▶️ Como rodar o projeto

### Front-end

```bash
cd frontend
npm install
npm run dev
```

Acesse `http://localhost:5173` no navegador.
